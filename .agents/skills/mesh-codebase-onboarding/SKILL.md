# Вход в кодовую базу МЭШ

Это локальная инструкция, не установщик. Прочитай корневые `AGENTS.md`,
`CLAUDE.md` и `docs/development/CODEBASE_MAP.md`. Пользователь определяет scope.

1. Проверь HEAD, ветку и dirty/untracked-файлы; сохрани чужую работу.
2. Прочитай manifest: world/run_at, точный порядок JS/CSS, worker,
   web-accessible hook. Для memo проследи HTML → JS/CSS отдельно.
3. Проследи цепочку hook → postMessage → bridge → store/event → consumer.
   Найди обратные связи: настройки → DOM/events → collector → worker/storage.
4. Найди все чтения и записи затрагиваемых globals, storage keys и событий.
   Зафиксируй различия учительского и трёх административных сборов.
5. Сопоставь код с документацией; противоречие пометь, не исправляй поведение
   без задачи. Комментарии о проверке вживую — историческое свидетельство,
   не гарантия текущего API.
6. Сформулируй минимальную область изменения и проверяемые инварианты.

Результат: входные файлы, цепочка зависимостей, затронутые функции,
неизвестные контракты и набор проверок. Не генерируй сборщик, backend,
рефакторинг или новый `CLAUDE.md` автоматически. Для тестов используй только
синтетические данные; не исследуй реальную сессию МЭШ.
